DIZZY HUNTERS – POKÉDEX GÄSTEBUCH

1. In Supabase > SQL Editor den Inhalt von SUPABASE_GAESTEBUCH.sql ausführen.
2. In GitHub (Hauptordner) folgende 5 Website-Dateien hochladen bzw. ersetzen:
   - gaestebuch.html
   - gaestebuch-pokedex.css
   - gaestebuch-pokedex.js
   - leitungszentrale.html
   - leitungs-gaestebuch.html
3. GitHub Commit changes, Deployment abwarten, Strg+F5.
4. Test: Gästebuch-Eintrag absenden, in Leitungszentrale > Gästebuch freigeben, öffentliche Anzeige prüfen.

Hinweise: Besucher dürfen nur Einträge einreichen, nicht selbst freigeben. Keine vertraulichen Daten im öffentlichen Gästebuch speichern. Ohne Captcha/Rate-Limit ist automatisierter Spam möglich; für stärkeren Spamschutz später serverseitige Validierung/Captcha ergänzen.
